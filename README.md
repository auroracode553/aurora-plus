# Aurora UI

Aurora UI 是基于 Vue 3 的通用组件库，提供带 `Au` 前缀的组件、命令式反馈服务、图标注册和 CSS 主题变量。组件库源码与使用说明位于 [`ui/`](./ui/)，完整 API 和示例集中在配套使用文档中。

## 目录

```text
aurora-ui/
├─ ui/          Aurora UI 组件库源码、主题与使用说明
├─ vitepress/   Aurora UI 使用文档
├─ README.md    仓库概览
└─ AGENTS.md   协作与文档边界规则
```

组件库的安装、引入方式、图标注册和主题定制说明请查看 [UI README](./ui/README.md)。
