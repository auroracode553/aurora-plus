# 介绍

Aurora Plus 是 Vue 3 通用组件库，提供基础、表单、数据展示、导航、反馈和应用组件，支持完整安装与按需导入。

## 组件范围

| 分类 | 当前能力 |
| --- | --- |
| Basic 基础组件 | [Button](/components/button)、[ButtonGroup](/components/button-group)、[Divider](/components/divider)、[Link](/components/link)、[Icon](/components/icon) |
| Form 表单组件 | [Input](/components/input)、[Textarea](/components/textarea)、[Select](/components/select)、[TreeSelect](/components/tree-select)、[DatePicker](/components/date-picker)、[TimePicker](/components/time-picker)、[ColorPicker](/components/color-picker)、[Slider](/components/slider)、[Switch](/components/switch)、[Checkbox](/components/checkbox)、[Form](/components/form) |
| Data 数据展示 | [Panel](/components/panel)、[Card](/components/card)、[ImagePreview](/components/image-preview)、[VirtualList](/components/virtual-list)、[VirtualTable](/components/virtual-table) |
| Navigation 导航 | [Pagination](/components/pagination)、[Dropdown](/components/dropdown)、[Menu](/components/menu)、[MenuBar](/components/menu-bar)、[MenuList](/components/menu-list)、[Tabs](/components/tabs)、[Tree](/components/tree)、[ContextMenu](/components/context-menu) |
| Feedback 反馈组件 | [Popover](/components/popover)、[Popconfirm](/components/popconfirm)、[Tooltip](/components/tooltip)、[Dialog](/components/dialog)、[Message](/components/message)、[MessageBox](/components/message-box) |
